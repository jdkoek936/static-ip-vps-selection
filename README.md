普通VPS默认走DHCP拿动态地址，机器一重启就可能换一个。跑网站的人最有体会：域名A记录还指着旧IP，访问当场断掉；做远程运维的，SSH客户端里存的地址失效，得先去控制台翻新IP；防火墙里写死的白名单规则也跟着一起废。静态IP要解决的就是这类问题。

具体到业务上，有五类场景是硬需求：

- 域名DNS解析指向这台机器的IP，IP一变全线中断
- 防火墙规则里引用了这个IP，换IP等于规则全废
- VPN和隧道需要固定的对端地址才能建立连接
- 邮件服务器靠一个稳定IP慢慢积累发信信誉，换IP等于从零开始
- SSH、RDP远程访问需要一个已知的、不会变的入口

做支付和金融接口的人对这条更敏感。Razorpay、Cashfree、PayU这类网关在生产模式下，要求商户对server-to-server的webhook回调和结算API做IP白名单；印度银行和NBFC开放API（account aggregator、payment initiation、reconciliation feeds）之前，也要你先登记一个固定的源IP。客户的MySQL、PostgreSQL、MSSQL防火墙同理，不把你的VPS IP加进白名单，报表脚本和ETL任务连不上。这些场景里IP一换，接口直接返回403，业务当场停摆。

## 挑静态IP VPS，先看三件事

价格差得远，配置单看着都差不多，区别主要在三处。

**第一，是不是独立IPv4。** 有些低价VPS号称静态IP，实际是NAT共享：一台物理机上的多个用户共用一个公网IP，靠端口映射区分。这种机器做不了80/443入站，建不了站；IP的历史记录也是多人共用的，做跨境业务时纯净度没法保证。社区里把这类叫“伪静态”，判断办法不复杂，看商家有没有明写“独立IPv4”、控制面板里分配给这台机器的IP数量是不是1、能不能自助修改反向解析（PTR）。三项都齐，基本就是独享。

**第二，IP属于哪一类。** 机房IP的ASN归属云服务商，这个信息公开可查，风控系统一眼能认出来。原生IP指IP的注册地与实际机房位置一致，IP库查询结果显示为当地，比如日本节点的IP在库里显示日本。双ISP再进一步，IP的注册ISP和实际路由ISP是两家不同的真实运营商，网络特征更接近家庭宽带。这三类在风控敏感的平台（ChatGPT、TikTok、流媒体）上表现差别明显，价格也依次往上走。

**第三，回程线路。** 同样的机器，走什么线路回国，晚高峰体验能差一倍。CN2 GIA是电信精品线，延迟低，价格高；AS9929是联通精品线，联通宽带用户优先；AS4837是联通普通优化，便宜够用；CMI是移动国际线路，香港节点常见；软银是日本主流家宽运营商，日本节点常见。

## 常见问题

### 静态IP在重启或升级配置后会变吗？

不会。六六云的说法是IP在VPS生命周期内不变，重启、重装、调整配置都不影响。行业里正规商家的做法也一样，升配只换CPU、内存、硬盘，地址跟着这台机器走。

### 怎么判断买到的是独立IP还是NAT共享？

三条：商家页面有没有明写“独立IPv4”；控制面板里分配给这台机器的IP数量是不是1；能不能自助修改反向解析（PTR）。NAT共享的机器做不了80/443入站，也没法改PTR。

### 买回来能直接当代理用吗？

不能。六六云卖的是裸Linux VPS，要自己装3X-UI、X-UI、Hysteria2这类工具才能变成可用的代理节点，官方页面没有预装这类软件。

### 静态IP VPS能建站吗？

能。域名A记录直接指向这个固定IP，SSL证书、防火墙规则、CDN回源都省事。前提是独立IPv4，NAT共享的那种做不了80/443。
